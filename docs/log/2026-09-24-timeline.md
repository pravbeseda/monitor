# 2026-09-24 — The timeline and tabs between skins

Mission control had merged, and the user asked for a first skin that is pleasant to use.
Four prototypes were drawn on synthetic data: a board of node cards, a timeline, a node ×
metric matrix, and orbs with a metric per arc. The user liked all four, chose the timeline
to build first, and asked for skins side by side as tabs, the last one chosen remembered.
The other three wait.

## The order against the roadmap

The roadmap put a forecast on mission control or the advisors next. The user asked for a
skin that draws the hub differently rather than a new field, and the timeline needs no new
field: it reads the event log evaluation has kept since stage 2.

## Anomalies in the history

An anomaly is computed on read and stored nowhere
([0036](../decisions/0036-an-anomaly-is-a-value-outside-its-weeks-band.md)), so the
prototype's purple hours had no source. Three answers were weighed: show anomalies only in
"now"; recompute them per past hour on every read; record their start and end in the log.
The user chose the third as the direction, and the lanes to show the levels now; the
recording is [#54](https://github.com/pravbeseda/monitor/issues/54).

## What the spec reviews changed

- **Remembering the skin moved from the hub to a tab click.** The draft had the hub set a
  cookie on every render and skip refreshes. A refresh cannot be told from an opening by the
  request, an upgrade reloads every open tab, a link to `/debug` from the board would have
  counted as a choice, and a hub that writes a cookie breaks
  [0023](../decisions/0023-proxy-holds-the-web-perimeter.md). The page now stores the
  choice when a tab is clicked, as it stores the zone.
- **"Quiet" became two states, "ok" and "reporting, nothing watched".** A node with no
  threshold read as well in green, which mission control's headline already refuses.
- **Freshness in the past was defined** rather than borrowed from "the state's staleness",
  which exists only at the present, and the reconstruction got an ADR of its own
  ([0038](../decisions/0038-a-lane-is-summarised-on-read.md)).
- **A removed threshold's level is shown only where it began.** Evaluation forgets it
  without an event, and every way of guessing its end painted a level over hours nothing
  judged — worst of all when the threshold was set again later.
- **The newest 50 changes are counted among the nodes shown**, so a removed node's history
  cannot crowd the list down to a handful.
- **A silence names its `silence_after`**, since the log's instant is when the hub noticed,
  and "now" names the last report — two times for one silence otherwise.

## What the code review changed

- **A tick between the page's two reads cut a level short.** The state and the log were read
  a moment apart, and a change written in between closed the span before it outside the
  window read; the log is now read from the window's start with no upper bound.
- **"Yesterday" and the hours were computed with clock arithmetic**, which lands on the wrong
  day where the clocks skip midnight and off the hour where they shift by half an hour; both
  now work on the calendar and put each cell on the hour by itself.
