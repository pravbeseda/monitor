Monitor

A personal control panel for one person's own machines and online services.

Monitor collects measurements — free disk space, memory, load, the storage left in a cloud account — and computes what they mean: whether something needs attention, how urgently, and whether a value is unusual for it. It alerts on changes that matter and stays quiet otherwise.

Monitor is a private application. It is not a public service: there is no sign-up and no shared server. Each installation is run by its owner, on the owner's own server, for the owner alone.

Google account access

An installation can watch how much storage is left in its owner's Google account. For that it asks Google for the narrowest access that shows the storage quota. It never reads, lists or changes the account's files, email or photos. The details are in the privacy policy.

Source code

The tooling is developed in the open at github.com/pravbeseda/monitor. No configuration, credentials or measurements are published there.
